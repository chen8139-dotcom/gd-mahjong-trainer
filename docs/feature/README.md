## 当前代码要点

- 新对局仅开放自摸鸡，旧流派规则数据保留用于旧对局读取。普通弃牌和鬼牌弃牌都不能胡；鬼牌弃牌也不能碰杠。抢补杠允许多人同时胡。
- `GameState` 保存本局鬼牌；多人抢杠记录候选和选择，`GameResult` 保留多赢家与各自番数；圈赛按各家分数变化累计，庄家在赢家中即连庄。
- 计算器支持指定鬼牌、录入百搭副露及从对局加载；胜率模拟中的多人抢杠按赢家人数平分该局胜利份额。
- AI 的规则正确性和策略尚有待验证事项，优先级与测试清单见 [AI 修复计划](./ai-zimoji-wildcard-fixes.md)。本次文档维护未运行测试。
