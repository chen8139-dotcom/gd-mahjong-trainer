# AI 强度基准报告

> **历史记录说明：** 2026-11-17 现状：本报告是历史分支、旧规则及旧统计口径下的数据，不可视为当前 main 或鬼牌模式基准。当前二档入口未实现；多人抢杠与鬼牌加入后须按 [AI 修复计划](./ai-zimoji-wildcard-fixes.md) 重新测量。

> 首份基准 · 2026-11-15 · 对应里程碑 M1（W0 缺口修复 + W6 基准闭环）
> 工具：`npm run tournament`（`scripts/tournament.ts`），此后每次合入 AI 相关改动前跑一次对打。

## 方法

- 对打协议：`npm run tournament -- --a <tier>:<难度> --b <tier>:<难度> --games N`
- 固定 seed（默认 10000 起连续），三流派按局轮换（tuidaohu / jipinghu / gangshi）；
  A 方交替坐 0/2 与 1/3（庄家固定 0）以抵消先手/庄位优势；
  对局全程跑牌数守恒不变量断言。
- 口径：胡牌率 = 胡牌局数 / 总局数（每局至多一胡）；点炮 = 被胡且非自摸（点炮者独付）；
  平均得分差 = 双方四人累计得分差 / 局数。
- 模拟冒烟：`npm run test:sim`（百局/千局，守恒 + 无异常 + 耗时预算）。

## W0 改动前后对比（tier1:expert vs tier1:novice，200 局）

| 指标 | 改动前 | 改动后 |
| --- | --- | --- |
| expert 胡牌率 | 42 (21.0%) | 43 (21.5%) |
| novice 胡牌率 | 80 (40.0%) | 75 (37.5%) |
| expert 自摸 | 16 | 13 |
| novice 自摸 | 38 | 33 |
| expert 点炮 | 11 | 14 |
| novice 点炮 | 57 | 58 |
| expert 平均番（胡时） | 1.71 | 2.21 |
| novice 平均番（胡时） | 2.77 | 2.95 |
| expert 平均得分/局 | −0.85 | −0.79 |
| novice 平均得分/局 | +0.85 | +0.79 |
| A−B 得分差/局 | **−1.71** | **−1.58** |
| 流局 | 78 | 82 |

### 关键发现（改动前基线）

**expert 头对头输给 novice（−1.71 点/局）**。拆解：expert 点炮仅为 novice 的 1/5
（11 vs 57），防守倾向明显；但胡牌率也只有 novice 的一半（21% vs 40%）——
`DANGER_WEIGHT=0.8` 的线性减分 + `FAN_WEIGHT=4` 的番数倾斜让它既不敢推进、
又常把牌走向慢的清一色方向。这为计划 §1 的判断（「对同样的可见信息加工得很浅，
老手档强度不足」）提供了量化锚点：W1–W4 的每一项都应推动 A−B 得分差向正方向移动，
「expert 稳定压过 novice」是后续工作的最低门槛。

## 结论

- **W0 验收通过**：expert 胡牌率 21.0% → 21.5%（不降 ✓）；百局/千局模拟守恒不变量
  通过（千局数据见下）；单测 160 例全绿（含新增暗杠/补杠/现物折算/公平性 10 例）。
- **对打指标变化在噪声范围内**（得分差 −1.71 → −1.58，200 局样本不足以分辨 0.1 点/局
  的差异）——符合预期：W0 是缺口修复而非强度项。expert 平均番（胡时）1.71 → 2.21，
  与暗杠/补杠带来的额外摸牌和更优听牌一致；点炮 11 → 14 轻微上升，与现物折算
  （对手池中的牌不再视为免费安全）方向相符，幅度可接受。
- **结构短板原样保留**：expert 仍输 novice −1.58/局。保守的线性危险度减分 +
  形同虚设的番数权重没有变动，这正是 W1（期望分）/W3（攻守切换）/W4（rollout）
  要解决的。此后每个工作流合入前跑 `npm run tournament`，用本表口径跟踪 A−B 得分差。

## 千局模拟（W0 后）

- 改动前百局（seeds 0–99）：通过（守恒 + 无异常），耗时 1002s。
- 改动后千局（seeds 100–1099）：**守恒不变量全程成立、无异常**；胡牌 556 / 流局 444，
  268,330 次决策。
- 耗时断言未过（均值 68.63ms > 50ms、p99 720ms > 500ms）。经微基准对照
  （`npm run bench:decide`，W0 前后代码同机同负载）：**冷路径均值 119.18 → 123.28ms
  （+3.4%，噪声内），暖路径 0.07 → 0.08ms——W0 无耗时回归**。~120ms 冷路径是向听首算的
  固有成本，两版代码相同，本机对 `avg < 50ms` 断言（SC-3）在 W0 前后均不成立；
  README 的「均值 < 20ms」系在其他机器/负载条件下测得。建议后续把 sim 耗时门改为
  相对回归断言（新版本 ≤ 旧版本 × 1.15）或按机型记录基线——留待维护者决策。
- 对真人陪练体感无影响：AI 单决策暖路径 ~0.1ms、冷路径 ~120ms，均远低于 Play 页 120ms
  的节奏延迟；rollout（W4）预算评估以本机冷/暖路径实测为基线。

## W1 对打基准（tier2:expert vs tier1:expert）

- 耗时（bench:decide，暖向听缓存）：二档 expert 均值 14.5ms / p50 0.18ms / p95 133ms，
  预算（均值 ≤ 300ms）内；一档冷/暖路径与 main 逐字节一致（W1 零回归）。
- 对打（200 局，seeds 10000–10199，交替座位）：

| 指标 | tier2:expert（实战） | tier1:expert（经典） |
| --- | --- | --- |
| 胡牌率 | 57 (28.5%) | 60 (30.0%) |
| 自摸 | 21 | 27 |
| 点炮 | **14** | 55 |
| 平均番（胡时） | 2.61 | 3.13 |
| 平均得分/局 | −0.23 | +0.23 |
| A−B 得分差/局 | **−0.47** | — |

- 解读：M2 验收「占优或持平」达成**持平**（−0.47/局，200 局样本的噪声量级）。
  行为画像显著变化：点炮降至一档的 1/4（14 vs 55）——期望分让二档在听牌阶段
  保留高价值等待、舍弃同样高效但危险的出牌；代价是胡牌数略少（57 vs 60）。
  期望分把「点炮风险 − 牌型价值」的权衡从一档的番数倾斜（方向性猜测）变成了
  精确计算，方向正确；强度反超待 W2（逐家危险度）/W3（攻守切换）补上防守精度、
  M5（VALUE_WEIGHT 网格调参）后以同口径对打复测。

## 校准

`npm run calibrate 50`（W0 改动后，50 局 1105 个分歧点）：

- 进张差分布：p50=−2 · p75=0 · p90=0 · p95=0 · max=0（expert 偏离纯效率时以让进张为代价，
  结构上不会高于 novice 的进张数）。
- 脚本机械建议 `COACH_THRESHOLDS.ukeireDiff = 1`；**决定保留 2**：p50=−2 说明
  expert 自己的分歧里「让 2 张进张」已是常见的风格性换牌（危险度/番数折算），
  阈值降到 1 会让教练在小损失上频繁提示，稀释「值得教学」的信号。
  已记录在 `coach.ts` 阈值注释中，二档落地后按档位各自复校。

## M3 对打基准（W2 读牌 + W3 攻守切换后）

### tier2:expert vs tier1:expert（200 局，seeds 10000–10199，与 M2 同 seeds 直接对比）

| 指标 | M2（W1 后） | M3（W2+W3 后） |
| --- | --- | --- |
| tier2 胡牌率 | 28.5% | **30.5%** |
| tier1 胡牌率 | 30.0% | 29.0% |
| tier2 点炮 | 14 | 16 |
| tier1 点炮 | 55 | 48 |
| A−B 得分差/局 | −0.47 | **−0.08** |

### tier2:expert vs tier1:novice（200 局，seeds 20000–20199）

| 指标 | tier2:expert | tier1:novice |
| --- | --- | --- |
| 胡牌率 | 25.5% | 31.5% |
| 自摸 | 20 | 22 |
| 点炮 | **12** | 60 |
| 平均番（胡时） | 2.73 | 2.35 |
| 平均得分/局 | +0.13 | −0.13 |
| A−B 得分差/局 | **+0.25** | — |

### 结论

- 对 tier1:expert 的得分差沿 M2→M3 单调收敛（−1.71 W0 前 → −0.47 W1 → −0.08 W2+W3），
  胡牌率首次反超（30.5% vs 29.0%），点炮保持在一档的 1/3（16 vs 48）。M3 验收
  「点炮率下降」以同口径量化达成。
- 对 tier1:novice **首次转正（+0.25/局）**：novice 式纯效率打法胡得多（31.5% vs 25.5%）
  但点炮 5 倍（60 vs 12）——守势切换 + 期望分的高价值路线在得分上压过激进路线，
  这正是「实战档」的设计目标（对人类有实质压力）。
- 剩余差距：对 expert 局胡时平均番 2.85 < 3.19，番数上限由 W5（鸣牌 EV）与 M5 调参
  推进；W4 rollout 为下一个大项。bench：二档均值 15.6ms / p95 137ms（预算内），
  一档路径不受 W2/W3 影响。

| --- | --- | --- |

### 结论与预判对账

- **Z1 ✓（预判 tier2 ≳ tier1）**：+1.16/局，胡牌率与平均番双优。有炮流派 M3 的
  −0.08/局在 zimoji 反转为 +1.16——「价值密度 ×3、忍牌零点炮代价」下精确期望分
  的收益被放大，§1.2 得到验证。
- **Z3 ✓（预判缓解或反转）**：−1.71/局（tuidaohu W0 前）→ +0.06/局（zimoji）——
  「expert 输给 novice」的病根（忍牌期点炮）消失；但也只是打平：fanTilt 权重 4
  抬不动番数（expert 胡时平均番 2.03 < novice 2.37），expert 靠胡牌率（48.5% vs 41%）
  换来微弱优势。
- **Z2 ✗（预判转正，实际 −0.38）**：接近打平但未转正。结算口径为每胡 ±2n
  （赢家方 +3n−n、输家方 −n−n），胡数几乎相同（93 vs 94）时番数差直接决定得分差——
  novice 纯效率路线胡时平均番反而更高（2.45 vs 2.24）。归因：tier2:expert 在 W1
  用期望分**替代**了 fanTilt 的全盘方向引导，中盘（向听 ≥2）完全无价值方向、
  仅听牌期分化；zimoji 价值密度 ×3 的环境下这是弱点而非简化。**留给 M5**：
  VALUE_WEIGHT 网格 + 中盘价值方向（保留小型 fanTilt 或将期望分推广到 1 向听）
  必须在 zimoji 口径下重标定——这正是本计划 §3「测量口径先行」的动机。
- **抢杠风险量化（§1.3/P1 修订）**：三组点炮列（=抢杠荣胡，含被抢方）合计仅 1 次
  ——当前补杠默认策略在 zimoji 的实际风险很低，W5 收口优先级可下调。
- **小样本教训**：40 局验收冒烟（seeds 10000–10039）曾显示 tier1:expert 67.5% 碾压，
  同配置 200 局（Z1）反转为 tier2 +1.16 胜出——对打结论一律以 ≥200 局为准。
- 档位塌缩（§1.1/P4）：由 zimoji 视图三组逐字节一致单测钉进 CI；基准中体现为
  novice/intermediate 四槽位行为不可区分。
